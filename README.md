# Origin-Weapon

Paper-плагин (Minecraft 1.21.10, Java 21) с предметами и оружием для рас сервера.
Каждый предмет — отдельный класс со своей механикой и своей секцией в `config.yml`.

## Возможности (план)

- Набор предметов для рас, пополняется со временем
- Для каждого предмета в `config.yml`:
  - `enabled` — выключить предмет целиком
  - имя, описание и параметры способностей (урон, кулдауны и т.д.)
- Автообновление `config.yml`: при добавлении новых предметов их секции дописываются
  в существующий конфиг, а уже изменённые админом значения сохраняются

## Сборка

```bash
gradle build          # jar появится в build/libs/
gradle runServer      # тестовый Paper-сервер 1.21.10
```

Сборка также запускается в GitHub Actions на каждый push — готовый jar лежит в артефактах.
